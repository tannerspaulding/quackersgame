# Quackers

A game by Mitchell, live at https://quackersgame.com.

Explore the worlds, find the hidden ducks and fill your Duck Log.

- `index.html` is the whole game (built file).
- `src/` holds the parts it's built from. Run `python3 src/build.py` to rebuild `index.html`.
- Add `?month=11` to the address to test the November-only Turkey Duck.
